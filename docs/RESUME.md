# Resume Summary

## Project Name

MERNForge AI

## Short Resume Description

Built MERNForge AI, a production-grade AI-powered adaptive learning platform for MERN stack education with JWT authentication, AI mentorship, code analysis, gamification, analytics, admin content management, and project roadmap generation.

## Resume Bullet Points

- Built a full-stack MERN learning platform using React, Node.js, Express, MongoDB, and Mongoose with modular MVC backend architecture.
- Implemented secure JWT authentication with bcrypt password hashing, refresh token rotation, protected routes, and role-based admin authorization.
- Designed a centralized AI service with Gemini, Groq, and OpenRouter fallback, structured response normalization, timeout handling, caching, and interaction logging.
- Developed adaptive learning features including levels, topics, progress tracking, weak topic analysis, accuracy tracking, and time-spent metrics.
- Created practice workflows for MCQs, coding challenges, code submissions, AI feedback, and submission history.
- Upgraded the coding workspace with Monaco editor, file tabs, starter templates, AI hints, analysis, submission, reset, and draft saving.
- Added gamification features such as XP, streaks, badges, leaderboard, and daily missions.
- Built analytics dashboards using Recharts for XP trends, accuracy trends, activity breakdowns, weak topics, and time tracking.
- Developed an AI Project Builder that generates MERN roadmaps with features, database models, API routes, frontend pages, milestones, and task checklists.
- Added admin content management APIs and UI for managing levels, topics, challenges, and badges.
- Hardened the application with Zod validation, Helmet, CORS, rate limiting, request sanitization, pagination, environment validation, and production-safe errors.
